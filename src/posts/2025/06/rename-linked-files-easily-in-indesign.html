 1. Introduction

Renaming linked images in Adobe InDesign can be tedious — especially when they appear in multiple documents.  

To solve that, I’ve created a small script that renames and relinks files with just one prompt.

2. What the Script Does

This script automatically:

- Renames the selected linked image file

- Updates all instances of the image across open documents

- Keeps folder structure and file formats intact

It’s designed to save time and reduce mistakes during layout editing.

3. When It’s Useful

This tool is ideal for:

- Designers cleaning up image names before final delivery

- Working with reused layouts or multi-language versions

- Anyone who edits InDesign documents with linked assets regularly

4. How to Use It

1. Open your InDesign file(s)

2. Select a linked image

3. Run the script

4. Enter a new name → Done!

The script will rename the file and update all links to it.
